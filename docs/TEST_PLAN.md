# Полный план ручного тестирования — Cream Nemesis Bot

> **Новые функции (сезоны, выход из чата, Quick-Kick, архив, pending TOVA, редактирование ЛС):** описание — [`NEW_FEATURES.md`](NEW_FEATURES.md); тест-план — [`TEST_PLAN_SEASONS.md`](TEST_PLAN_SEASONS.md). Пройдите его **локально до** обновления на сервере.

Два аккаунта: **A** (админ: `ADMIN_IDS` и/или `ADMIN_USERNAMES`) и **B** (игрок).  
Отмечай `[x]` по мере прохождения.

Ссылки `t.me/c/...` собираются из `.env`, не зашиты в код.  
Для продакшен-проверки нужен доступ к **трём** ориг-чатам из ТЗ (см. § «Чаты и темы»).

## Перед стартом

- [x] `.env` заполнен: `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_USERNAMES`, чаты, `TOPIC_*`, `ADMINS_*`
- [x] Бот запущен: `python bot.py` или `run.bat` (**перезапуск после любой правки `.env`**)
- [x] В консоли: `Logging initialized` и `journal_mode=wal`
- [x] Есть файл `logs/bot.log`
- [x] Бот — админ чата `MAIN_CHAT_ID` (для модерации)
- [x] A и B нажали `/start` боту в ЛС (иначе не придут ЛС по TOVA / approve)

| `VSA_CHAT_ID` | `4398028064` | `-1004398028064` | 1 (зал VSA) |

Снять ID темы: зайди в тему → `/topicid`.  
Если `TOPIC_*` пустой — кнопка **не** ведёт на битую ссылку, а показывает «тема не настроена».

Не темы (внешние URL, темы создавать не нужно): firebase-таблицы, Google Sheets «Бомбардиры».
