После нажатия на кнопку Статистика бот показывает личную статистику пользователя, который нажал на эту кнопку. Все данные собираются и обновляются ботом автоматически на основе подтверждённых матчей TOVA.

Отображается следующая информация:

TOV сыграно: общее количество сыгранных матчей
Очки: количество набранных очков
Победы: количество выигранных матчей
Ничьи: количество матчей, завершившихся вничью
Поражения: количество проигранных матчей
Забито / Пропущено: общее количество забитых и пропущенных голов
Разница голов: разница между количеством забитых и пропущенных голов
Лучший бомбардир: футболист пользователя, забивший больше всего голов в текущем сезоне
Сухие матчи: количество матчей, завершённых без пропущенных голов

Каждый пользователь видит только свою личную статистику. Данные автоматически обновляются после подтверждения результата матча администратором TOVA.
